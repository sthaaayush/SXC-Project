# GoingGreen – Greenhouse Farming Platform

**A web application built using JSP, Servlet, and MySQL to promote sustainable agriculture through greenhouse farming information, setup bookings, and e-commerce functionality.**

---

## Project Overview
GoingGreen is a full-stack platform developed during the SXC hackathon. It enables users to access information about greenhouse farming, book greenhouse setups, and purchase related products online. The system is designed with a clean, responsive interface and a reliable backend powered by JSP and Servlet.

---

## Features
- **Greenhouse Info**: Explore educational content on greenhouse farming practices and benefits.
- **Booking System**: Reserve greenhouse setups with a simple and structured process.
- **E-commerce Functionality**: Browse and purchase greenhouse products such as tools and materials.
- **Responsive Design**: Optimized layout for both desktop and mobile viewing.

---

## Tech Stack
- **Frontend**: HTML5, CSS3, Bootstrap  
- **Backend**: Java (JSP & Servlet)  
- **Database**: MySQL  
- **Other Tools**: GitHub (version control), Apache Tomcat (deployment)
